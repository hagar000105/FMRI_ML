# FMRI Machine Learning Project

This repository contains the final assignment project in the fMRI + Machine Learning course.  
The project explores how machine-learning models can predict cognitive or behavioral scores based on brain activity recorded using functional MRI.

## Project Structure

**Final_Assignment_Ziv_Tirosh_Hagar_Yitzhaki.ipynb**  
  The main Colab notebook that includes:
    Data loading and preprocessing  
    Feature extraction  
    Model training  
    Predictions  
    Evaluation metrics  

## Project Goals

1. Load and preprocess fMRI data.
2. Extract meaningful features.
3. Train machine-learning models that predict a given target score.
4. Evaluate the performance of the models using standard metrics.
5. Visualize the results and discuss conclusions.

## Technologies Used

 **Python**  
 **Google Colab**  
 **NumPy**  
 **Pandas**
 **scikit-learn**
 **Matplotlib / Seaborn**

## Evaluation Metrics

The project includes several evaluation metrics such as:

**Correlation Coefficient (Pearson)**
**MAE** - Mean Absolute Error
**RMSE** - Root Mean Squared Error
Scatter plots comparing predictions vs. true values

## How to Run

1. Open the notebook in Google Colab:
   Upload the `.ipynb` file manually
   Or clone the repository and place the notebook inside your Colab environment

2. Make sure you upload your dataset to Colab before running the cells.

3. Run the notebook step by step from top to bottom.
